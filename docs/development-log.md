# 开发日志

## 2026-04-25 - M1 / M1.5 基础原型

- 游戏是纯回合制。玩家点击“下月”或按空格推进月份；模拟不随帧率运行。
- 控制器命名为 `TurnController`，不使用实时 `GameLoop`。
- 地图使用 Canvas 2D 绘制，界面使用原生 DOM 渲染函数。
- 地图为 80×80 方格，当前格子尺寸为 40×40 像素。
- 建筑必须接到已完工的路或桥才会生效；路和桥自身视为已连接。
- 桥只能建在河流格上，作为道路网络的一部分。
- 建造和拆除支持拖拽；右键取消当前工具。
- 住房按建筑聚合计算，不模拟单个居民或单户家庭。
- 水不是库存资源，只作为河流、泉眼或水井提供的服务覆盖。

## 2026-04-26 - M2 地图、视觉与治理扩展

- 地图改为按随机种子生成，包含三种原型：渭河盆地、太行山阙、江南水乡。
- 新增林地和荒野：林地建造会自动伐林、延长工期并返还少量钱；荒野建造更贵，且阻止该地住房升级。
- 新增热点：桑林提高附近作坊布产，古井泉眼提供小范围水源。
- 地形和建筑全部由 Canvas 程序化绘制，不依赖外部图片素材。
- 小地图显示地形、建筑、热点和当前视野，可点击或拖拽跳转视角。
- 生产建筑会在月结时显示浮动产出数字。
- 诏令系统包含赋税、仓廪、治化三槽位；月初调政免费，年中调政花费 20 钱。
- 随机事件在宽限期后按冷却和概率触发，事件选择可影响资源、气数、持续修正或折扣。
- 声望里程碑会一次性发放奖励，并提供气数奖励。

## 2026-04-26 - M2.5 气数制

- 固定任期目标已移除，当前胜负由“气数”决定。
- 气数初始 100，上限 200；气数归零时任期结束。
- 评价以在任月数为主，称号为：早夭、平庸、兴治、盛世、雄主、千秋。
- 每月气数变化由 `QishuSystem.updateQishu` 计算：基础流逝、空城惩罚、民心、治安、声望、粮食、深宅府第、断路比例和里程碑都会参与。
- 事件不应直接永久改写三项指标；指标影响应作为有时限的事件修正进入 `IndicatorSystem`。
- 右侧面板现在是气数面板，显示本月气数明细、最近一次性变动和当前持续修正。
- 事件弹窗打开时，玩家必须先回应事件，才能推进月份、建造、拆除或调诏令。

## 2026-04-27 - M3a-3D 真 3D 渲染

- 渲染层从 Canvas 2D 推倒重做为 Three.js（r162），通过 `<script type="importmap">` 从 unpkg CDN 加载，无需任何打包步骤。
- 所有模拟（sim/、model/、data/）保持不变；只重写 `src/app/Renderer.js` + 新增 `src/app/scene/*` 模块。
- 摄像机：`PerspectiveCamera` + `OrbitControls`，左键由游戏自己处理建造，中键拖动平移，右键拖动旋转，滚轮缩放。`maxPolarAngle = 1.25` 防止视角穿到地下。
- 地形：单一 `BufferGeometry`，每个 tile 提交两个三角形 + 必要的侧面（与较低地形邻接的悬崖面）。河流凹陷、丘陵抬升、林地略高。`vertexColors` 携带每格颜色。
- 建筑：每种类型一个 factory，组合 `BoxGeometry` / `ConeGeometry` / `CylinderGeometry` 等基本几何体得到 3D 剪影；屋顶统一用 4 段锥（pyramid hip-roof）匹配中国古代建筑感。住房 5 个阶层有视觉差异。
- Picking：单独一张不可见的水平 `PlaneGeometry` 作为 raycast 目标，光线 → 平面交点 → tile 坐标。建筑 mesh 不参与拾取，简化逻辑。
- Ghost / 拖拽预览：在地面上贴半透明色块（绿/黄/红三档），覆盖拟建建筑的整片占地。
- 服务覆盖圈：选中井/市/仓/祠/学时，遍历 Chebyshev 半径内每格贴半透明金色方块。
- 浮动数字：DOM 元素，每帧把 world 坐标投影到屏幕坐标后定位，避免在 WebGL 里画字。
- 小地图改回顶视 2D，但用渲染器 `getViewportPolygon()` 投影 4 个屏幕角到地面，画出一个梯形作为视野框。
- 新建/拆除/升级会被 `signature()` 检测到，单点重建那栋建筑的 mesh，不影响其他。新任期通过 `controller.onNewTerm` 钩子触发 `renderer.resetForNewState()` 清除全部 mesh 和动画。
- 默认动画 tick 改为 100 ms / 帧（10 fps），兼顾旗帜飘动和浮动数字过渡，进一步动画（烟雾、农田作物季节、河流波纹）排在 M3b。

## 2026-04-29 - M3a-2 经济与升级工期

- 新增第 6 个资源 **木材 (wood)**，初始 80，仓上限 200。每个建筑 def 增加 `woodCost` 字段，建造和升级都先扣木材；木材不够直接建不了。
- 新建建筑 **伐木场 (lumberCamp)**，2×2 占地、3 工人、本身免木材以避免链路死锁。每月基础产 4 木材，3 格内有林地翻倍到 8。每月有 8% × 等级概率把 1 块周围林地砍成平原（确定性走 `state.rng`），逼玩家长期看林地分布。
- **维护费指数化**：从 `cost × 0.1 × level` 改成 `cost × (0.08 + 0.04 × level²)`。一级建筑 12% 月维护、二级 24%、三级 44%——升级真正是权衡。
- **岁贡 (annual tribute)** 每年正月触发：`30 + 里程碑 × 20 + floor(prestige / 30) × 10`。声望越高朝廷期待越高。完税正常，欠缴一半以上 -12 气数 + 民心 -8/治安 -5 持续 6 月，欠缴一部分 -6 气数 + 民心 -4 持续 4 月。
- **升级吃工期**：每级升级有 `upgradeSeasons[level-2]` 个月，期间建筑按旧等级运行但 labor 占用按新等级算（升级费工人）。可点「中止升级」全额退钱 + 退木材。视觉：升级中显示蓝色脚手架包裹建筑（区别于黄棕色的初建脚手架）。
- **拆除返还修正**：从 `floor(cost × 0.25 × level)` 改成 `floor(cost × 0.25)`——三级建筑拆除不再倍数返钱，避免「升级—拆除」循环套利。升级过程中拆除会先全额退还 pending 的钱和木材。
- **施工建筑也占 labor**：`completeConstruction` 和 `effectiveLaborLevel` 协同——建造期间按基础 labor 占用、升级期间按目标 level 占用。再也不能在劳力捉襟见肘时无脑铺设施。
- 顶栏 + 资源明细面板新增木材计数、木仓上限、产消明细。建造栏每个按钮显示「N 钱 · M 木」。建筑详情面板升级按钮显示「N 钱 · M 木 · K 月工期」，进行中显示「中止升级」。
- 调试面板加「加 50 木」按钮。
- stateHash 包含 wood、resourceCaps、upgradePending、lastTributeYear，确定性回放仍然成立。
- 测试 +10 项：木材初始/扣减/不足拒建、升级吃工期、取消升级退款、维护费指数公式、岁贡公式、岁贡执行、岁贡欠缴罚气数、伐木场林地加成、拆除固定返款。共 37/37 通过。

- 这次只做“程序纹理 + 少量 Canvas 生成纹理”，不加入贴图包、PBR 材质库或美术管线，避免 M3 原型复杂度膨胀。

## 2026-05-03 - 性能优化第三轮（找到锁帧元凶）

- **拆掉自动低功耗判定**：`detectRenderQuality` 之前用 `hardwareConcurrency <= 4 || deviceMemory <= 4` 判低功耗。Chrome 的 `navigator.deviceMemory` 四舍五入到 2 的幂、上限 8GB —— 4GB 内存的机器报告 4，命中条件；同时 4 核及以下的常见 i5 笔记本也命中。一旦命中就锁 30fps、关 AA、关阴影。第二轮把节流去掉了，但这一层 lowPower 标志仍然把 minFrameMs 锁死在 1000/30，所以"空白地图也没 60 帧"。现在只认显式 `?quality=low` 才进低功耗模式，默认走全速 rAF。
- **像素比默认降到 1.0**：之前默认 1.5，Retina/4K 上等于多渲染 2.25× 像素，对低面数风格化场景没有视觉收益。`?quality=high` 才放到 1.5。
- **抗锯齿默认关**：默认 off，`?quality=high` 开。低面数场景关掉 AA 几乎看不出差异，省下的 fragment 时间换帧率。
- **地形 mesh 关掉 DoubleSide**：80×80 地形的三角形绕序本来就对（顶面法线 +Y、侧面外法线），DoubleSide 让 GPU 把每个片元算两遍；关掉后地形片元工作量大致减半。
- **场景去掉 softFill 平行光**：HemisphereLight 已经提供天空-地面双向漫反射补光，再叠一盏 DirectionalLight 是浪费每片元一次 dot product。同时把 hemi 和 sun 强度各上调一点，亮度持平。
- **新增 FPS 显示**：右上角"操作提示"下方加一个常驻的 `FPS xx` 小框（CSS class `.fps-overlay`），每 0.5 秒按滚动窗口刷新；玩家不需要打开 DevTools 也能看实时帧率，便于判断卡顿是否真的解决。
- 更新页面资源版本参数到 `0.6.2-perf`。

## 2026-05-03 - 性能优化第二轮（修复上一轮未生效的卡顿）

- **修复上一轮 rAF 改造的回归**：上一轮日志说"setInterval(100ms) 改为 requestAnimationFrame，与显示器 VSync 对齐"，但 `startAnimationLoop` 的 rAF 回调里仍然写死 `if (elapsed < 100ms) return;`，等价于继续以 10 fps 渲染，相机拖动、建造预览和动画都还是卡的。本轮把节流去掉，普通设备直接吃满 rAF（一般 60 fps），低功耗设备限到 30 fps。
- **动画改为按真实时间推进**：原来 `animTick * 0.08`、`animTick * 0.1`、`floatingNumbers ttl=90` 都是按 10 fps 帧数算的；解开节流后会快 6 倍。`Renderer.tick(dt)` 改为接收真实秒数，`animTime` 累积，`animateSceneDetails` 用 `animTime * 0.8`、`animateWaterLayer(animTime)`、`FloatingLayer.update(dtSec)` 按秒老化，老存档里的 `note.ttl=90` 自动按 `/10` 折算回 9 秒。
- **阴影贴图按需重渲染**：场景几乎全静态，把 `renderer.shadowMap.autoUpdate` 关掉，只在 `draw({syncBuildings:true})` 或 `rebuildMap()` 后用 `shadowsDirty` 标志触发一次 `needsUpdate`。每帧省掉一次完整 shadow pass，是 GPU 大头。
- **旗帜不再投影**：`makeFlag` 的每段 plane 加 `noShadow` 标记。原本旗帜每帧都摆动，会让阴影贴图不停脏掉，配合上一条改动后就完全静止了；视觉上 0.4×0.2 的小旗本来也看不出影子。
- **Tooltip 节流**：`showTooltip` 用 `hoverTile + 模式` 拼一个 key，相同 key 时只更新位置 CSS，不重写 `innerHTML`。鼠标在同一格上滑动时不再每像素重排版。
- 更新页面资源版本参数到 `0.6.1-perf`。

## 2026-05-03 - 性能优化

- **森林渲染改造**：将数百个独立树干/树冠 Mesh 合并为 InstancedMesh，200 个森林格原需 ~1200 个 draw call，现仅需 5 个（1 个树干 + 4 种颜色叶片）。
- **Ghost 预览层优化**：拖拽建造时不再每帧创建/销毁 `MeshBasicMaterial`，改为预建 4 种颜色的共享 Material + Mesh 对象池复用。
- **Coverage 覆盖层优化**：选中服务建筑时的半径显示，从数百个独立 Mesh 改为 2 个 InstancedMesh（内部 + 边框），大半径建筑效果显著。
- **动画循环改造**：从 `setInterval(100ms)` 改为 `requestAnimationFrame`，与显示器 VSync 对齐，消除固定 10fps 的卡顿感。
- **Minimap 按需重绘**：小地图不再每 N 帧固定重绘，改为仅在镜头移动或建筑变化时标脏重绘。
- **消除冗余渲染**：`draw()` 不再重复调用 `renderer.render()`，由 `tick()` 的 rAF 统一渲染，减少每次鼠标拖拽的双重渲染。
- **阴影优化**：shadow map 从 PCFSoftShadowMap 改为 BasicShadowMap，分辨率从 1024 降至 768，shadow camera 视锥从 ±55 收紧到 ±42。
- **雾距收紧**：远雾距离从 155 降至 120，让 GPU 更早剔除远处片元。
- **热点装饰减面**：桑林/泉眼的 SphereGeometry、TorusGeometry 面数降低（8→6/4 段, 16→10 段），并共享 Material 而非每个独立创建。
